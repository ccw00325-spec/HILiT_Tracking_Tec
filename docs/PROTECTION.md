# 기술 보호와 도용 탐지

공개 코드는 기술적으로 복사를 막을 수 없습니다. 그래서 이 저장소는 **핵심 자산을 빼고, 허락 범위를 정하고, 복사되면 찾아내는** 구조를 씁니다.

## 층별 구조

| 층 | 방식 | 할 수 있는 것 | 할 수 없는 것 |
|---|---|---|---|
| 라이선스 | 비상업 허락, 상업 사전 승인, 출처 표시, 표시 삭제와 우회 금지, 파생물 동일 조건 | 위반 시 법적 근거 | 위반 자체를 막지는 못함 |
| 가중치 분리 | 공개 저장소와 이력에 가중치 없음 | 가중치를 받아 갈 수 없음 | 코드와 문턱값은 볼 수 있음 |
| 받는 사람별 가중치 표시 | 승인받은 사람에게만 암호화해 전달하고, 사본마다 다른 표시를 넣음 | 유출된 사본이 누구 것인지 대조 | 재학습이나 강한 변형 뒤에는 약해질 수 있음 |
| 학습 권리 유보 | `LICENSE` 9항과 `ai.txt` | 저작권 유보 의사를 표시 | 법적 효과는 나라마다 다르고, 플랫폼 약관이 따로 허용한 범위는 막지 못함 |
| 파일 지문 | 파일마다 다른 `HILiT-PUB-2026·CW·…` | 어느 파일에서 왔는지 특정 | 지우면 사라짐. 다만 삭제 자체가 라이선스 위반 |
| 소유권 상수 | `OWNERSHIP` 값 | 번들에 값이 남음 | 코드에서 지우면 사라짐 |
| 코드 지문 | 주석, 공백, 지역 이름과 무관한 조각 비교 | 표시를 지우고 압축한 사본도 단서를 찾음 | 다른 언어로 옮기거나 새로 구현한 코드는 못 찾음 |
| 가중치 해시 | SHA-256 비교 | 같은 파일 발견 | 다시 저장한 파일은 못 찾음 |

## 복사되면 어떻게 알 수 있나

GitHub 안에서는 `tools/watch-github.mjs` 가 지문과 고유 이름이 든 공개 코드, 새 포크를 찾습니다.

- `watch-copies` 워크플로가 매주 돌고, 새 항목이 있으면 실패합니다. 예약 실행이 실패하면 GitHub가 저장소 주인에게 메일을 보냅니다. 공개 로그에는 건수만 남습니다.
- `tools/watch-install-windows.ps1` 로 PC에 주간 작업을 걸면 코드 검색, 조회와 복제 통계까지 보고서로 남고 Windows 알림이 뜹니다.

의심되는 사이트나 파일은 직접 검사합니다.

```bash
node tools/detect-copy.mjs https://의심되는-사이트.example
node tools/detect-copy.mjs <받아 둔 폴더>
```

주소를 검사하면 그 페이지와 페이지가 불러오는 스크립트를 읽습니다. 앱 내부나 서버에서만 도는 코드는 볼 수 없습니다.

## 넣지 않은 것

실행될 때 저작자 서버로 위치를 몰래 알리는 코드는 넣지 않았습니다. 이용자 개인정보를 동의 없이 보내게 되고, 공개 코드라 쉽게 지울 수도 있기 때문입니다.

## 발견했을 때

1. 주소, 파일, 탐지 결과, 날짜를 저장합니다.
2. 비상업 이용인지, 출처를 표시했는지 확인합니다.
3. 조건을 어겼다면 `LICENSE` 9항에 따라 통지합니다.
4. GitHub 게시물은 DMCA 절차로 삭제를 요청할 수 있습니다. 법적 대응은 변호사와 상의합니다.

코드 지문의 일치 비율은 단서입니다. 일치한다는 사실만으로 침해가 확정되지는 않습니다.

## English

Public code cannot be technically copy-proof. Protection here relies on withholding weights, license terms, per-file fingerprints, a code-similarity index, and scheduled monitoring. There is no hidden phone-home. Similarity results are leads, not proof of infringement.
