# 가혹 조건 시험

정확도는 쉬운 장면이 아니라 아래 조건에서 확인해야 합니다. 시험 영상은 권리와 동의 문제로 공개하지 않으므로, 이용자는 권리가 정리된 자기 영상을 써야 합니다.

## 가중치 없이 돌리는 합성 시험

```bash
node tools/eval-synthetic.mjs           # 일곱 장면 × 두 추적 방식, 시드 8개
node tools/eval-synthetic.mjs --check   # 기준(eval/baseline.json)보다 나빠지면 실패. CI가 매번 돌립니다
node tools/eval-synthetic.mjs --sweep swapScoreMin=0.4,0.6,0.8     # 값을 바꿔 비교
```

장면: 군중 가림, 같은 유니폼 교차, 조명 급변, 흔들림과 번짐, 화면 밖 재등장, 밀집 군중. 검출은 위치 오차와 놓침을 넣어 흉내 냅니다. 도형으로 그린 장면이라 **회귀를 잡는 용도이며 실제 영상의 정확도가 아닙니다.** 값을 바꾸는 일은 실제 영상 평가를 통과한 뒤에 합니다.

자기 영상은 `tools/eval-track.mjs` 로 같은 기준으로 채점합니다.

| 조건 | 재현할 장면 | 확인할 실패 | 기대 동작 |
|---|---|---|---|
| 역광 | 해를 등진 대상, 어두운 무대의 LED 조명 | 대상을 배경과 혼동 | 확신이 낮으면 놓침으로 표시 |
| 심한 흔들림 | 손떨림, 빠른 팬, 모션 블러 | 상자가 배경에 붙음 | 카메라 보정이 근거 부족을 알리고 오판하지 않음 |
| 완전 겹침 | 대상이 다른 사람 뒤로 지나감 | 겹친 사람으로 넘어감 (ID 전환) | 다시 나타날 때 확인하고, 불확실하면 사용자에게 물음 |
| 같은 유니폼 | 같은 옷을 입은 여러 선수 | 다른 선수를 대상으로 착각 | 자동으로 잇지 않고 후보를 보여 줌 |
| 화면 밖 재등장 | 대상이 화면을 나갔다 돌아옴 | 다른 사람에게 붙음 | 위치와 외형이 함께 맞을 때만 후보로 올림 |
| 작은 대상 | 멀리 있는 사람 | 검출 실패 | 사람을 찾지 못한 구간을 숨기지 않음 |

## 재는 값

- 보이는 구간에서 상자와 정답의 IoU 0.5 이상 비율
- 틀린 상자로 정상 표시한 비율
- 대상이 없는데 있다고 표시한 비율
- 대상 전환 횟수와 사용자에게 물은 횟수

## 사용자 보정 동작

AI가 놓치거나 다른 사람으로 착각했을 때 사용자가 고칠 수 있어야 합니다.

1. 불확실한 구간을 영상 타임라인에 표시합니다.
2. 그 구간의 후보 상자를 보여 주고 사용자가 고르게 합니다.
3. 고른 지점부터 다시 추적합니다.
4. 사용자가 고친 내용을 다른 영상의 외형 판단에 옮기지 않습니다.

## 시험 원칙

- 합성 영상 결과를 실사 성능으로 쓰지 않습니다.
- 모델이 만든 정답과 사람이 검수한 정답을 구분해 적습니다.
- 평가에 쓴 영상을 학습에 쓰지 않습니다.

## English

Test against backlight, heavy motion blur, full occlusion, identical uniforms, off-screen re-entry, and small targets. Test footage is not published. Do not report synthetic results as real-world performance.
